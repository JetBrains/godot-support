JetBrains Rider Integration for Godot

This official JetBrains addon improves the development experience when using Rider with the Godot Editor, making setup seamless and ensuring optimal defaults out of the box.

Key Features

  • Automatic Rider Detection
    Finds all Rider installations on your system and lets you select the preferred version directly in Godot settings.
  • Godot ↔ Rider Connection
    Connects the Godot editor to the selected Rider installation. This enables Open in Rider from the FileSystem dock, Open in Godot from Rider, and debugging the current scene from Rider.
  • Rider Toolbar Menu
    Adds a Rider menu to the Godot toolbar to start Rider, switch the recommended external editor preset on or off, and open the external editor settings.
  • Optimized Editor Configuration
    Applies a set of recommended Godot editor settings for a smooth Rider-based workflow.

Why use this addon?

Setting up an external IDE can be error-prone and time-consuming. This addon removes friction and ensures that Rider works correctly with Godot from the start—so you can focus on building your game instead of configuring your tools.

Getting Started

  1. Install the addon from the Asset Store
  2. Click the Rider button in the Godot toolbar
  3. Choose "External Editor Settings…" and select your Rider installation
  4. Enable "Use external editor preset" in the same menu
  5. Choose "Start Rider" to open the project in Rider

About Rider

JetBrains Rider is a fast and powerful IDE for game development with support for Godot, Unity and Unreal Engine workflows.
